## About RJ Nexus

RJ Nexus is the home of **RJ CMS** and its growing ecosystem. This organization hosts the CMS core and publishes the plugins and themes that extend it.

RJ CMS is a modern, self-hosted content management system built on **Laravel 12**. It is modular by design: plugins and themes are fully isolated from the core, so they can be installed, updated, and removed without touching it. You run it on your own server and keep full ownership of your data.

It ships with **RJBuilder**, a visual drag-and-drop page builder with **60+ widgets**, a dual AI engine, 17 languages with per-language URLs, and a browser-based installer that works on any shared hosting or VPS.

> **Latest release.** RJ CORE 1 (v1.8.3) is the first official stable release of RJ CMS. See the [Changelog](https://github.com/rj-nexus/rj-nexus/blob/main/CHANGELOG.md) for details.

## Repository conventions

To keep the ecosystem easy to browse, packages published under this organization follow a simple naming scheme.

| Prefix | Used for | Example |
|--------|----------|---------|
| `rj-plugin-*` | Plugins | `rj-plugin-form-builder` |

Every package repository should include a README with installation steps, supported RJ CMS versions, a changelog, and an MIT license, and should use the topics `rj-cms` and `rj-plugin`.

## Contributing

Contributions of every size are welcome, from bug reports to whole new plugins.

1. Open an issue before starting work on a large change.
2. Fork the repository and create a feature branch.
3. Follow PSR-12 coding standards.
4. Open a pull request with a clear description.

Have a question or suggestion? Start a thread in [Discussions](https://github.com/orgs/rj-nexus/discussions).

Want your plugin or theme listed? Open an issue in [rj-nexus/rj-nexus](https://github.com/rj-nexus/rj-nexus/issues) with the repository link and a short description.
