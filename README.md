## About RJ Nexus

RJ Nexus is the home of **RJ CMS** and its growing ecosystem. This organization hosts the CMS core and publishes the plugins, themes, widgets, and tools that extend it.

RJ CMS is a modern, self-hosted content management system built on **Laravel 12**. It is modular by design: plugins and themes are fully isolated from the core, so they can be installed, updated, and removed without touching it. You run it on your own server and keep full ownership of your data.

> **Development notice.** RJ CMS is under active development. Expect bugs, incomplete features, and breaking changes. It is not recommended for production use yet.

## Repository conventions

To keep the ecosystem easy to browse, packages published under this organization follow a simple naming scheme.

| Prefix | Used for | Example |
|--------|----------|---------|
| `rj-plugin-*` | Plugins | `rj-plugin-form-builder` |
| `rj-theme-*` | Themes | `rj-theme-starter` |
| `rj-widget-*` | RJBuilder widgets | `rj-widget-pricing-table` |

Every package repository should include a README with installation steps, supported RJ CMS versions, a changelog, and an MIT license, and should use the topics `rj-cms` plus `rj-plugin`, `rj-theme`, or `widget-system`.

## Contributing

Contributions of every size are welcome, from bug reports to whole new plugins and themes.

1. Open an issue before starting work on a large change.
2. Fork the repository and create a feature branch.
3. Follow PSR-12 coding standards.
4. Open a pull request with a clear description.

Want your plugin or theme listed here? Open an issue in [rj-nexus/rj-nexus](https://github.com/rj-nexus/rj-nexus/issues) with the repository link and a short description.
